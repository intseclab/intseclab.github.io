{{< project title="Secure inference data center" >}}
A data center built to keep frontier AI models secure from tampering and theft.
It uses STPA-Sec, which emphasizes unknown-unknown attack vectors, alongside
formal methods and other high-assurance approaches. The methodology is set out
in the RAND report [Highly Secure Inference Data Centers](https://www.rand.org/pubs/research_reports/RRA4827-1.html).
